# RoadGuard Research Component

This folder houses the academic and empirical research documentation for **RoadGuard: Deep Learning-Based Road Damage Detection and Severity Assessment**.

## Directory Structure

```
research/
├── literature_review/
│   ├── LITERATURE_REVIEW.md       # Comprehensive review of 6 verified peer-reviewed publications
│   ├── literature_matrix.md       # Comparative benchmark matrix across datasets, models, metrics
│   └── papers_database.bib        # BibTeX bibliography with official DOIs
├── methodology/
│   ├── SEVERITY_INDEX_METHODOLOGY.md # Mathematical formulation & validation of Road Damage Severity Index (RDSI)
│   └── MODEL_ARCHITECTURE.md      # Detailed YOLOv8 decoupled head, P2 small-crack branch, loss formulation
└── experiments/
    ├── experimental_setup.md      # Training hyperparameters, hardware, dataset splitting protocol
    └── experimental_results.md    # Empirical results, class-by-class benchmark metrics, and ablation discussion
```

All citations, DOIs, mathematical formulations, and experimental frameworks adhere to peer-reviewed academic rigor.
